¿Qué ofrece GlucoAPI?

Todo lo necesario para registrar y dar seguimiento a la glucosa en tu aplicación.

🩸

Registro de mediciones

Guarda el valor de glucosa en mg/dL junto con la fecha, la hora y el momento de la medición.

📈

Historial por usuario

Consulta todas las mediciones de cada usuario y filtra por fechas para ver su evolución.

🔔

Clasificación automática

Cada registro se clasifica según su rango: bajo, normal, elevado o alto.

🔒

Datos protegidos

La información de salud se maneja de forma privada y solo se accede con autorización.

Cómo funciona

Integrarlo es cuestión de tres pasos.

Crea un usuario

Registra a la persona que llevará su control de glucosa dentro de BloodHealth.

Envía la medición

Haz una petición POST con el valor de glucosa y el momento en que se tomó.

Consulta el historial

Obtén los registros en formato JSON y muéstralos en tu aplicación.

Endpoints de GlucoAPI

Ejemplo de rutas y formato de datos. Ajústalos a los de tu proyecto.

Rutas disponibles

POST /api/glucosa Registrar
GET /api/glucosa Listar todas
GET /api/glucosa/{id} Por ID
GET /api/usuarios/{id}/glucosa Historial
PUT /api/glucosa/{id} Actualizar
DELETE /api/glucosa/{id} Eliminar

Ejemplo de petición

POST /api/glucosa
Content-Type: application/json

{
  "usuarioId": 1,
  "valor": 92,
  "unidad": "mg/dL",
  "momento": "ayunas",
  "fecha": "2026-10-26T07:30:00"
}
